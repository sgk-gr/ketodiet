# Spiros Health & Low-Carb Control Panel Dashboard (105kg ➔ 90kg)

Ένα εξατομικευμένο, σύγχρονο και διαδραστικό **Control Panel Dashboard** για τον Σπύρο, ειδικά σχεδιασμένο για:
- **Low-Carb Διατροφή & 16:8 Διαλειμματική Νηστεία** (Απώλεια 15 κιλών: 105kg ➔ 90kg).
- **Αντιφλεγμονώδη υποστήριξη & Προστασία για Στένωση Σπονδυλικού Σωλήνα (Low-Impact).**
- **Supabase Cloud Integration** με πίνακες που φέρουν πρόθεμα `spiros_`.

---

## 🌟 Κύρια Χαρακτηριστικά

1. **📊 Weight Tracker (105 ➔ 90 kg):**
   - Διαδραστικό γράφημα με ορόσημα (100kg, 95kg, 90kg) και εφέ confetti.
   - Αυτόματος υπολογισμός αποφόρτισης μέσης (**1kg απώλεια = 4kg λιγότερη πίεση** στους οσφυϊκούς σπονδύλους).
   - Καταγραφή βάρους, δείκτη πόνου μέσης (1–10) και σημειώσεων.

2. **⏰ Ζωντανός Χρονοδιακόπτης 16:8 (Fasting Countdown):**
   - Live αντίστροφη μέτρηση σε δευτερόλεπτα για το **Παράθυρο Φαγητού (12:00 – 20:00)** και τη **Φάση Νηστείας/Αυτοφαγίας (20:00 – 12:00)**.
   - Οδηγός επιτρεπόμενων ροφημάτων 0 θερμίδων (νερό, σκέτος καφές, πράσινο τσάι, σόδα).

3. **🥗 Οδηγός Τροφών (Επιτρέπονται vs Απαγορεύονται):**
   - Φίλτρα: **✅ Επιτρέπονται**, **⚠️ Με Μέτρο**, **❌ Κόβονται Μαχαίρι**.
   - Σήμανση αντιφλεγμονώδους δράσης και ειδικά οφέλη για τους σπονδύλους (Ω-3, Μαγνήσιο, κτλ.).
   - Δυνατότητα προσθήκης νέων τροφών.

4. **🍲 Εβδομαδιαίο Μενού & Συνταγές (7 Ημέρες / 21 Γεύματα):**
   - Μεσημεριανό (12:00), Σνακ (16:00), Βραδινό (20:00).
   - Αναλυτικά υλικά, οδηγίες εκτέλεσης, μακροθρεπτικά συστατικά (<25g καθαροί υδατάνθρακες).
   - Έτοιμη λίστα αγορών σούπερ μάρκετ με κουμπί εκτύπωσης.

5. **🚶 Φροντίδα Σπονδυλικής Στήλης & Ήπια Άσκηση:**
   - Οδηγός 4 ασφαλών ασκήσεων (Στατικό ποδήλατο με πλάτη, περπάτημα σε ίσιωμα, κολύμβηση, διατάσεις αποφόρτισης).
   - Tracker ενυδάτωσης δίσκων (στόχος 3L) με κουμπιά `+250ml` / `+500ml`.
   - Καθημερινή λίστα συνηθειών (Daily Habits checklist).

6. **🗄️ Supabase Cloud Database:**
   - Πίνακες: `spiros_weight_logs`, `spiros_foods`, `spiros_meals`, `spiros_daily_logs`, `spiros_settings`.
   - Ενσωματωμένο One-Click SQL Setup script generator & Dual-Mode local caching.
